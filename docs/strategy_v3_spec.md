## 方針

構造は v2 の short_F2off_F3off(ショート専用・HTF日足EMA50フィルター・ttmスクイーズ)で確定させ、
**有意性検定のデータ窓を全利用可能期間(2025-11-20〜2026-07-22, 約8ヶ月)に拡張**して検定力を上げる。
- 2025-11-20開始の理由: 日足EMA50が2025-10-01起点のデータでシードされるのが11月中旬のため
  (全指標が完全にウォームアップ済みの最初の時点)
- **成績要件(Sharpe≥1.5, リスク3%)の評価期間は従来どおり2026-01-01〜2026-07-22**で変更しない。
  拡張窓は仮説検定(エッジは実在するか)のみに使う。標本を増やす正当な手段であり、
  評価期間の付け替えではない。

## 事前登録する検定対象(順次検定、最初に合格した時点で停止)

## ゲート条件(拡張窓 2025-11-20〜2026-07-22 で判定)

- trades ≥ 30
- bootstrap p < 0.05(トレードR平均、n=10000, seed=42)
- random-entry p < 0.05(n=1000, seed=42, 同一窓・同一サイジング)
- 多重比較ガード: rand_p < 0.02 **または** 同一構成の2h適用(同拡張窓)で Sharpe > 0.5
