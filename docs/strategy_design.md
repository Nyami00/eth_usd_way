# ETH/USD ボリンジャーバンド・スクイーズ型トレンドフォロー戦略 — 設計書

作成: 2026-07-22 / 設計・検証: Claude Fable 5, 実装: Claude Opus 4.8

## 1. 目的と成功基準

- 対象: ETH/USD(現物価格、Coinbase ETH-USD)
- 評価期間: 2026-01-01 〜 2026-07-22(約6.6ヶ月)
- 成功基準(ユーザー要求):
  - **年率シャープレシオ ≥ 1.5**(バーレベルのエクイティ収益率から年率換算)
  - **1トレードあたりの口座リスク = 3%**(初期ストップまでの距離に基づくポジションサイジング)
  - 統計的有意性テストを通過した戦略のみ採用(p < 0.05)
  - モンテカルロ・シミュレーションで過剰最適化でないことを確認

## 2. 戦略仮説

ボラティリティは平均回帰しつつクラスター化する。バンド幅が歴史的に狭い「スクイーズ」状態は
エネルギーの蓄積を示し、その解放(ブレイクアウト)は持続的なトレンドの起点になりやすい。
暗号資産は伝統資産よりモメンタム持続性が強く、スクイーズ→ブレイクアウト→トレンド追随の
構造が機能しやすいという仮説を立てる。

## 3. 戦略仕様 v1(プロトタイプ)

- 時間足: 1h(基本)。15m は感度分析用。
- ベース指標: ボリンジャーバンド BB(20, 2.0)
- スクイーズ判定(2案を比較):
  - A案(TTM型): BB が Keltner Channel(20, 1.5×ATR20) の内側に完全に入った状態
  - B案(バンド幅パーセンタイル): BandWidth = (Upper−Lower)/Middle が直近 L=120 バーの
    下位 q%(初期値 q=20)にある状態
- セットアップ: スクイーズが S バー以上継続(初期値 S=6)
- エントリー(スクイーズ解放+ブレイクアウト):
  - ロング: 終値が BB Upper を上抜けて確定
  - ショート: 終値が BB Lower を下抜けて確定
  - トレンドフィルター: EMA(200) に対する位置(ロングは close > EMA200、ショートは逆)
- 執行モデル: シグナルはバー確定時に判定し、**次のバーの始値で約定**(ルックアヘッド禁止)
- 初期ストップ: エントリー価格 ∓ k1×ATR(14)(初期値 k1=2.0)
- イグジット: シャンデリア型 ATR トレーリングストップ(k2×ATR(14)、初期値 k2=3.0)。
  ストップはバー内の高値/安値タッチで約定(保守的に価格はストップ水準、スリッページ加算)
- ポジションサイズ: リスク額 = 資産×3%、数量 = リスク額 / (初期ストップ距離)。レバレッジ上限 5x。
- コスト: 手数料 0.05%/片道 + スリッページ 0.02%/片道(感度分析で 2 倍に引き上げて確認)

## 4. 統計的有意性プロトコル(本実装前のゲート)

プロトタイプのトレード結果に対して以下を実施し、**両方で p < 0.05** の場合のみ先へ進む:

1. **ブートストラップ検定**(トレード単位のRマルチプル): H0「平均トレード収益 ≤ 0」。
   1万回リサンプリングで平均が 0 以下になる確率を p 値とする。
2. **ランダムエントリー・置換検定**: 実戦略と同じトレード数・保有期間分布・方向比率・
   同一リスクサイジングのランダム戦略を 1,000 回生成し、シャープレシオの分布を作る。
   p = P(ランダム ≥ 実戦略)。タイミングの情報価値(エクスポージャー効果を超える分)を検定。
- 追加条件: トレード数 ≥ 30(検定力確保)。

## 5. 最適化プロトコル

- グリッドサーチ: BB期間, スクイーズ閾値 q / KC倍率, S, k1, k2, トレンドフィルター種別
- 過剰最適化の抑制:
  - パラメータ数を最小限に保つ
  - 単独最良点ではなく**プラトー**(近傍パラメータも良好な領域)から選択
  - 最適化後に有意性テストを再実行(多重検定になる点は MC で補正的に評価)

## 6. モンテカルロ・プロトコル(過剰最適化チェック)

1. **トレード・ブートストラップ**(復元抽出, 1万回): シャープ・最大DDの分布、
   P(Sharpe > 0)、P(Sharpe > 1.5)、5%点を報告
2. **トレード順序シャッフル**: 3%複利サイジング下でのDD分布(経路リスク)
3. **パラメータ摂動MC**: 採用パラメータの近傍(±1ステップ)をランダムに 500 通り評価し、
   成績分布を確認。採用点が孤立したスパイクなら過剰最適化と判定
4. **エントリータイミング・ジッター**: エントリーを ±1 バーずらしても成績が崩れないか
- 合格目安: ブートストラップ 5%点の Sharpe > 0、P(Sharpe>1.5) が十分高い、
  パラメータ摂動の中央値 Sharpe が基準近傍を維持

## 7. リスクと限界(事前に明記)

- 評価期間 6.6 ヶ月・単一レジームでの検証であり、将来の成績を保証しない
- ユーザー要求により 2026 年データでの最適化を許容するため、当該期間はインサンプル。
  過剰適合リスクは MC とプラトー選択で緩和するが、完全には排除できない
- 手数料・スリッページは想定値。取引所・注文方式によって実効コストは変わる
