## 1. 最適化(グリッドサーチ)

固定: bb_n=20, bb_k=2.0, atr_n=14, squeeze_mode=ttm, fee=0.0005, slip=0.0002,
リスク3%/トレード, レバ上限5x, flip_on_opposite=false

探索次元(フルグリッド 9,600通り/TF):
| パラメータ | 候補 |

- 対象TF: 15m(主)、1h(参考)
- long-only はプロトタイプで大幅負(Sharpe −3.7)のため除外。"both" は7月の反発などの
  ロング機会を許容するために残す。
- 指標配列(EMA各種, ATR, BB, KC)は事前計算しキャッシュ。シミュレーションはイベントループのみ。

### 選択基準(単純な最大化をしない)
1. 候補条件: trades ≥ 30 かつ Sharpe ≥ 1.5(日次リサンプル年率、評価期間2026-01-01〜)
2. **プラトー・スコア** = 自身+全1ステップ近傍(各次元±1、direction除く)の Sharpe 平均
3. プラトー・スコア最大の候補を採用(同率なら trades が多い方)
4. 採用構成で有意性テスト(boot n=10000, rand n=1000)を再実行し、boot_p<0.05 かつ
   rand_p<0.05 を確認。不合格なら次点プラトーを検証(最大3候補まで。全滅なら構造再設計に戻る)

## 2. モンテカルロ(過剰最適化・頑健性チェック)

採用構成に対して実施。全て seed 固定で再現可能に。

| テスト | 方法 | 事前登録する合格基準 |
|---|---|---|
| MC1: 日次ブロック・ブートストラップ | 日次リターンを block=5 の定常ブロックで 10,000 回再抽出→Sharpe分布 | 5%点 Sharpe > 0 |
| MC2: トレード・ブートストラップ | Rマルチプルを復元抽出(10,000回)、3%複利で資産経路→リターン/DD分布 | 5%点の総リターン > 0 |
| MC3: トレード順序シャッフル | 順序のみ入替(10,000回)→maxDD分布 | 95%点 maxDD < 35% |
| MC4: パラメータ摂動 | 全1ステップ近傍+ランダム2次元摂動200通りの成績分布 | 近傍の70%以上で Sharpe > 0、近傍中央値 Sharpe ≥ 1.0 |
| MC5: エントリー・ジッター | 各エントリーを0/1/2バー(等確率)遅延、500回 | 中央値 Sharpe ≥ 1.0 |

- MC1/MC2/MC3 は「成績の運・経路依存性」、MC4/MC5 は「過剰最適化(パラメータ/タイミングの
  カーブフィット)」を検出する。
- 判定は上記基準で機械的に行い、結果は合否とも全て報告する。
