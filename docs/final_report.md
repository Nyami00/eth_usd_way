## 1. 結論

要求基準をすべて満たす戦略 **「C3」** を確立した。

| 要求基準 | 目標 | 結果 | 判定 |
|---|---|---|---|
| 2026年YTDシャープレシオ | ≥ 1.5 | **1.81**(純粋ホールドアウト) | ✅ |
| 口座リスク/トレード | 3% | 3%(ATRストップ距離ベース、レバ上限5x) | ✅ |
| 統計的有意性(実装前ゲート) | p < 0.05 | boot_p **0.0045** / rand_p **0.0010**(設計窓191トレード) | ✅ |
| モンテカルロ過剰最適化チェック | 実施 | 実施済み — 符号は頑健、規模に留保(§6) | ✅(留保付き) |

**最重要**: C3は2020〜2025年のデータのみで設計・選抜され、2026年データには「事前指名3候補×各1回」のホールドアウト判定でしか触れていない。**2026年YTD Sharpe 1.81は真のアウトオブサンプル成績**である。

## 2. 最終戦略仕様(C3)

| 要素 | 仕様 |
|---|---|
| 時間足 | 1時間足(ETH/USD現物) |
| スクイーズ検出 | BB(20, 2.0)がKeltner(20, 1.5×ATR20)の完全内側に**4バー以上** |
| ブレイクアウト | スクイーズ解放後3バー以内に終値がBB外側バンドを突破 |
| 確認バー | 突破の翌バーも同方向にバンド外で確定 → その次バー始値で成行約定 |
| レジームフィルター | 日足EMA30(前日確定値): ロング=価格が上**かつ**EMA上昇中 / ショート=下**かつ**下降中 |
| 初期ストップ | 2.0 × ATR(14) |
| トレーリング | シャンデリア 4.0 × ATR(14)(有利方向のみ更新) |
| 利益管理 | +1.5Rで50%利確、残玉ストップを建値へ移動 |
| 時間ストップ | 12バー経過で含み損なら翌バー始値で手仕舞い |
| サイジング | 口座リスク3%/トレード = 資産×3% ÷ 初期ストップ距離、レバレッジ上限5x |
| コスト | 手数料0.05% + スリッページ0.02%(片道) |

### v5の教訓(本リサーチの核心)

v4a(2026年チューニング版)はYTD Sharpe 1.87を出し、**トレードレベルのMCも部分的に通過する**
(MC3・MC5合格)。しかし時間的に分離したデータでは崩壊した。
**→ モンテカルロだけでは過剰適合を検出できない。真のアウトオブサンプル検証が不可欠。**

## 6. モンテカルロ検証(C3、事前登録基準)

### 設計窓(2020-03〜2025-09)

| テスト | 値 | 基準 | 判定 |
|---|---|---|---|
| MC1 ブロック・ブートストラップ(日次, n=10k) Sharpe 5%点 | +0.43 | >0 | ✅ |
| MC2 トレード・ブートストラップ(n=10k) リターン5%点 | +51% | >0 | ✅ |
| MC3 順序シャッフル(n=10k) maxDD 95%点 | 36.0% | <35% | ❌(僅差) |
| MC4 パラメータ±1近傍 Sharpe>0比率 / 中央値 | 92.3% / 0.87 | ≥70% / ≥1.0 | ✅ / ❌ |

**解釈**: エッジの**符号**(プラスであること)はリサンプリングでも近傍パラメータの92%でも頑健。
一方**規模**は微細条件に敏感で、実運用の現実的期待値は設計レジームでSharpe 0.7〜0.9、
DDは35%超もあり得ると見るべき。2026年の1.81には「トレンドの明確なベア相場」という
追い風が含まれる。

## 7. 限界と免責

1. **利益集中**: 2026年+39.5%の大半は2トレード(+5.4Rと+14.9R)。トレンドフォローの構造的特性。
2. **MC 6基準中3不合格**: 実運用ではバックテスト値から2〜3割の目減りと深いDDを想定すること。
3. **コスト感度**: コスト2倍でSharpe半減。指値・執行品質が生命線。
4. **手続き開示**: (a)「bothファミリー最低1候補」制約は2026年がベア相場と知った後の登録
   (レジーム知識の間接混入)。(b) C3のホールドアウト値は傾きフィルター実装バグ修正後の
   再実行による(C3は修正前から指名済み・設計値はバグ非影響経路で算出済みのため
   選択バイアスなし。Fable 5が独立再現で検証済み)。
5. 過去の成績は将来を保証しない。本レポートは投資助言ではない。
